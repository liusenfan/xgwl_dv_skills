# Demo 系统黑盒示例规格

仅用于展示字段写法和验证工具链，不代表真实 DUT；版本 demo-1。

边界为完整 Demo 传输模块。外部可发送带长度的事务、控制输出 ready 及复位、观察输出内容；内部存储和流水线不可见。

- DEMO-01：输入长度支持 1–16 字节；接收成功后，输出按原顺序返回相同长度及内容。长度选择不改变检查规则。
- DEMO-02：输出 valid=1 且 ready=0 时，valid 与 data 保持稳定直至握手。检查需确认反压确实发生；恢复 ready 后可完成传输。
- DEMO-03：事务中复位丢弃未完成输出；释放复位后，新的合法事务可正常完成。复位有效期间不产生有效输出。

未给出端到端最大延迟，不据策略看门狗推导性能规格。平台尚未实现，示例只规划能力。
