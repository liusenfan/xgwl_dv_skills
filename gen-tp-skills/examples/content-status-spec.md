# Demo 内容状态示例规格

版本 demo-status-1；虚构的单槽传输模块，仅用于展示 TP 内容完整性，不作为真实项目依据。

## S1 接口与初始化

无配置寄存器。所有握手在 clk 上升沿判定；rst 为同步高有效复位，保持一个上升沿即清空槽位；复位期间 out_valid=0，不接收输入。释放复位后的首个上升沿即可接收。复位只用作本示例前置，不在本次测试范围内验证其全部行为。

输入为 in_valid、in_ready、in_data[7:0]；输出为 out_valid、out_ready、out_data[7:0]。valid && ready 表示接受一笔。槽位空时 in_ready=1；接受输入后的下一周期 out_valid=1、out_data 等于接受数据，直到输出握手。槽位占用时 in_ready=0；输出握手后的下一周期槽位为空。本例不要求同时输入和输出。

## S2 输出背压

非复位期间 out_valid=1 且 out_ready=0 时，out_valid 和 out_data 保持至握手。每个被接受输入只输出一次，输出内容不变。

## S3 连续传输性能

需要验证连续传输吞吐。负载为复位后 in_valid 持续为 1、out_ready 持续为 1；从首次输入握手的下一个上升沿起，统计 100 个上升沿中输出握手数，指标为次数/100（笔/周期）。合格阈值尚未给出，待设计补充。本例不从 S1 推导值替代待确认的性能验收承诺。
